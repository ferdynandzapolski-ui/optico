# Canonical References Index

This index lists the primary sources governing the design and implementation of GOIR.

| Source | Description |
| :--- | :--- |
| **LLVM LangRef** | Governs LLVM IR syntax, semantics, and intrinsic definitions. |
| **Clang ASan Docs** | Provides reference for AddressSanitizer's instrumentation and runtime behavior. |
| **CHERI TR-947** | Governs capability-based memory safety and C/C++ guide for CHERI. |
| **SoftBound (PLDI'09)** | Governs spatial memory safety via base/bound metadata. |
| **CETS (ISMM'10)** | Governs temporal memory safety via identifier/lock metadata. |
| **SoftBound+CETS Revisited (2024)** | Modern perspective on combining spatial and temporal safety. |
| **Memarian Provenance (POPL'19)** | Governs formal semantics of pointer provenance (PNVI variants). |
| **WG14 N2364** | C standard committee proposal for pointer provenance. |
| **Katsumata (POPL'14)** | Governs the theory of graded monads/comonads used for IR refinement. |
| **Gaboardi et al. (ICFP'16)** | Governs grading for resource tracking and sensitivity analysis. |
| **Iris Framework** | Governs formal separation logic proofs for concurrent systems. |
| **RustBelt** | Provides methodology for proving safety of 'unsafe' code via Iris. |
