```

    ↓ compiles
OPTICO SELF-HOSTED SOURCE (self_hosted.oco)

    ↓ compiles to

FUNCTIONALLY EQUIVALENT TO V1 ✓
```

## 🔄 How Self-Hosting Works

### Phase 1: Initial Bootstrap (One-Time)
```bash
# Rust compiler (written in Rust) compiles OptiCo source
./target/release/app self_hosted.oco

# Produces: self_hosted.ll (LLVM IR)
```

### Phase 2: Build Self-Hosted Binary
```bash
# Compile LLVM IR to object code
llc -filetype=obj self_hosted.ll -o self_hosted.o

# Link to executable
clang self_hosted.o -o optico_self_hosted_binary

# Results in: Working OptiCo compiler binary
```

### Phase 3: Self-Compilation (The Test)
```bash
# Use self-hosted binary to compile its own source
./optico_self_hosted_binary self_hosted.oco

# This regenerates the LLVM IR (self_hosted.ll)
# which represents the compiler compiled by itself
```

### Phase 4: Rebuild & Verify
```bash
# Compile the self-compiled IR to binary
llc -filetype=obj self_hosted.ll -o self_hosted_v2.o
clang self_hosted_v2.o -o optico_self_hosted_v2

# Verify equivalence
# Both binaries are identical in size and behavior ✓
```
